# Godot Learning

A game development learning journal using **Godot and C#**, covering gameplay programming, game design, player feedback, testing, and releasing small games.

This repository contains coaching notes, exercises, decisions, and project histories. Godot source projects are maintained separately.

## Projects

- [Basic Structure](projects/01-basic-structure/LEARNING.md) — foundations sandbox.
- [Lights Out](projects/02-lights-out/LEARNING.md) — first completed game.
- [Crate-pushing](projects/03-crate-pushing/LEARNING.md) — a small Sokoban-style puzzle, currently in planning.

See [LEARNING.md](LEARNING.md) for the active project, learner background, and tooling, and [AGENTS.md](AGENTS.md) for the coaching agreement.
