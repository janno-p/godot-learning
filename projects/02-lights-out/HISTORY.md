# 02 — Lights Out history

Current status and the agreed brief live in [LEARNING.md](LEARNING.md). This file preserves the original plan, milestone observations, and chronological decisions.

Source links point to the current [GitHub project directory](https://github.com/janno-p/godot-projects/tree/main/02-lights-out); milestone descriptions record the state at the time, not necessarily the current source contents. Generated exports and temporary test copies are not stored in the repository.

## Original proposed implementation checkpoints

1. Get a minimal project running and understand scenes and nodes.
2. Make a board interactive and implement its rules.
3. Add a solvable starting board, win detection, and restart.
4. Make the rules and outcomes understandable through UI and feedback.
5. Playtest, fix problems, and export a playable build.
6. Reflect on what worked and choose the next project or a small design variation.

Single-cell input complete by learner report and source inspection: `InitializeButtonPressedHandlers()` connects each button once from `_Ready()`, using a per-iteration `index` copy in its callback. Full neighbor move and coordinate cleanup complete by learner report and source inspection: the button callback calls `ToggleButtons(index)` and then redraws once. `ToggleButtons()` toggles the clicked cell and bounds-checks all four orthogonal directions, delegating each state change to `ToggleButton()`.
